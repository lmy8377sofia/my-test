         PDF 电子盖章工具 —— Windows 打包 exe 指南
═══════════════════════════════════════════════════════════════

本文件说明如何在 Windows 10/11 上，把源码打包成免安装的
「PDF电子盖章工具.exe」。

──────────────────────────────────────────────
第一步：安装 Python（一次性，约 2 分钟）
──────────────────────────────────────────────
1. 打开：https://www.python.org/downloads/windows/
2. 下载 Python 3.10 或更高版本（推荐 3.11/3.12 的 64 位版）
3. 运行安装程序，【必须勾选】最下方的：
       ☑ Add python.exe to PATH
   （勾上这个，命令行里才能直接使用 python）
4. 点 Install Now 完成安装

验证：按 Win+R，输入 cmd 回车，执行：
       python --version
   看到 Python 3.1x 即成功。

──────────────────────────────────────────────
第二步：一键打包（约 5 分钟）
──────────────────────────────────────────────
1. 把整个「PDF电子盖章工具」文件夹放到一个简单路径，
   例如：D:\PDF电子盖章工具
   （不要放桌面 / C:\Program Files 等带权限的目录）
2. 双击文件夹里的  build_exe.bat
3. 脚本会自动完成三件事：
       [1/3] 安装依赖（PyMuPDF、Pillow、numpy、PyInstaller）
       [2/3] 运行内置自检（验证去白底/自动盖章/导出，全部通过才继续）
       [3/3] PyInstaller 打包
4. 看到「打包完成：dist\PDF电子盖章工具.exe」即成功。

产出文件：dist\PDF电子盖章工具.exe
  · 绿色单文件、免安装，双击即用
  · 可以单独拷贝到 U 盘/桌面/其他电脑使用

──────────────────────────────────────────────
第三步：验证 exe（可选但推荐）
──────────────────────────────────────────────
1. 双击 PDF电子盖章工具.exe
2. 点「① 上传印章」选 assets\demo\示例印章_白底.jpg（白底红章）
3. 点「② 打开 PDF」选 assets\demo\示例文档.pdf（2 页示例）
4. 点「★ 自动盖章」→ 第 1 页章应盖在「华信检测有限公司」上，
   第 2 页章应盖在「项目成员」标题上
5. 点「导出 PDF」→ 得到 示例文档_已盖章.pdf，用阅读器打开检查

──────────────────────────────────────────────
常见问题
──────────────────────────────────────────────
Q1 提示“python 不是内部或外部命令”
   → 安装 Python 时没勾选 Add to PATH。
     解决：重装 Python 并勾选；或手动把
     C:\Users\你的用户名\AppData\Local\Programs\Python\Python311
     加到系统环境变量 PATH。
Q2 pip 下载太慢 / 超时
   → 改用国内镜像：把 build_exe.bat 里的 pip 命令加上参数：
     python -m pip install -i https://pypi.tuna.tsinghua.edu.cn/simple -r requirements.txt
Q3 杀毒软件拦截或报毒
   → PyInstaller 单文件 exe 偶发误报（无签名 + 自解压特征）。
     添加信任即可；介意的话改用「启动盖章工具.bat」绿色运行。
Q4 打包失败，提示权限错误
   → 文件夹别放 C:\Program Files / 桌面；放到 D 盘或用户目录再试。
Q5 自检（[2/3]）提示失败
   → 一般是网络安装依赖不全，重跑 build_exe.bat；
     仍失败就把窗口文字截图发给我。

──────────────────────────────────────────────
手动命令（不用 bat 时的等价操作，任选一种即可）
──────────────────────────────────────────────
在文件夹里打开 cmd：

    pip install -r requirements.txt pyinstaller
    python pdf_stamp.py --selftest
    python -m PyInstaller --noconfirm --clean --onefile --windowed ^
        --name "PDF电子盖章工具" --icon assets\app.ico pdf_stamp.py

exe 输出在 dist\ 目录。
