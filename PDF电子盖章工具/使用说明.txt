              PDF 电子盖章工具  使用说明
═══════════════════════════════════════════════════════════════

一、这是什么
    本地桌面软件：给 PDF 电子盖章。
    · 白底红章图片自动去白底，盖出来像真实公章（无白方块）
    · 支持点击放置、拖动移动、调大小 / 透明度 / 旋转
    · 支持多页、每页多枚章
    · 支持「按关键词自动盖章」批处理
    · 仅本地运行，不上传网络

二、安装与启动（两种方式任选）

  方式 A：绿色便携版（推荐）
    1. 解压本文件夹到任意位置（不要放 C 盘系统目录）
    2. 双击「启动盖章工具.bat」
       · 首次运行会自动检查并安装依赖（需要联网，约 1-2 分钟）
       · 之后再运行即秒开
    3. 也可以用打包好的 exe：
       把 dist\PDF电子盖章工具.exe 拷贝到桌面，双击即用（免安装）

  方式 B：源码运行
    1. 安装 Python 3.10 或更高版本：
       https://www.python.org/downloads/windows/
       安装时务必勾选 "Add python.exe to PATH"
    2. 双击「启动盖章工具.bat」，或在命令行执行：
       pip install -r requirements.txt
       python pdf_stamp.py

  打包成 exe（可选）：
    双击「build_exe.bat」，完成后 exe 在 dist\ 目录。

三、三步盖章法（手动）

    1. 上传印章：点顶栏「① 上传印章」，选择白底红章图片（JPG/PNG）
       —— 左侧会显示"去白底 + 调透明度"后的效果
    2. 打开 PDF：点「② 打开 PDF」，选择要盖章的文件
    3. 盖章：
       · 在页面任意位置【单击】→ 以点击处为中心盖上一枚章
       · 在已有的章上【单击】选中（蓝色虚线框）→ 按住【拖动】可移动
       · 选中后，左侧滑条实时调整：直径(mm) / 透明度 / 旋转角
       · 点「导出 PDF」→ 另存为「原文件名_已盖章.pdf」（绝不覆盖原文件）

四、一键自动盖章

    点顶栏「★ 自动盖章」，按固定规则批处理：
    规则 A（第 1 页 封面）：自动找到含「华信检测」或「有限公司」
            的公司名行，把章盖在该行文字中心（55mm、透明度0.90）
    规则 B（第 2 页 项目成员）：自动找到「项目成员」标题，
            把章盖在标题中心（不是表格底部）

    定位跟文字走（不写死坐标），换一版 PDF 也能大致盖对。
    关键词找不到时，程序会提示，此时手动补盖即可。

五、快捷键

    Ctrl+O      打开 PDF
    Ctrl+S      上传印章
    Ctrl+E      导出 PDF
    Ctrl+0      适合窗口
    Ctrl+滚轮   缩放页面
    Delete      删除选中的章
    ← / →       上一页 / 下一页

六、常见问题

    Q1 盖出来的章有白方块？
       → 左侧勾选「去除印章白色背景」（默认已勾选），重新盖章。
    Q2 章太大 / 太小？
       → 选中章后，把「直径（mm）」调到 35~60 之间；A4 页面 55mm 是常规公章大小。
    Q3 章是斜的？
       → 选中章，把「旋转角」调回 0。
    Q4 导出后原文件会变吗？
       → 不会。导出永远另存为新文件「xxx_已盖章.pdf」。
    Q5 自动盖章没盖到？
       → 若关键词不在第 1/2 页，程序会提示，请手动盖章。
    Q6 杀毒软件报毒？
       → PyInstaller 打包的程序偶有误报，添加信任即可；也可改用「启动盖章工具.bat」绿色运行。

七、自检（可选）

    命令行执行：
        python pdf_stamp.py --selftest
    会自动生成测试印章与 2 页示例 PDF，验证：去白底、自动定位、尺寸换算、导出与文件体积。

    生成示例素材（含白底红章 JPG + 示例 PDF）：
        python pdf_stamp.py --demo
    素材输出到 assets\demo\ 目录，可用来练习。
